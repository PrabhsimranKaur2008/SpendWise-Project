# StudentSpend Budget Buddy

Build a modern, professional and fully responsive website called StudentSpend – Student Expense Tracker.

PURPOSE:

A simple expense management platform designed specifically for college students to manage their daily expenses, monthly budgets and savings.

DESIGN:

- Premium, modern dashboard UI.

- Use navy blue, white and soft green colours.

- Clean cards, rounded corners and attractive charts.

- Responsive design for mobile and laptop.

- Easy navigation and beginner-friendly interface.

FEATURES:

1. Dashboard

- Display total monthly expenses.

- Display remaining budget.

- Show total savings.

- Show recent transactions.

- Display a monthly spending chart.

2. Add Expense

- Add expense name.

- Enter amount.

- Select category.

- Select date.

- Add optional description.

- Save the transaction.

3. Expense Categories

   Include:

- Food

- Transportation

- Education

- Shopping

- Entertainment

- Accommodation

- Other

4. Monthly Budget

- Allow students to set a monthly budget.

- Show budget used and remaining.

- Display a warning when spending approaches the budget limit.

5. Expense History

- Show all transactions.

- Allow users to edit and delete expenses.

- Add category and date filters.

6. Analytics

- Display interactive pie charts and bar graphs.

- Show spending by category.

- Show weekly and monthly spending patterns.

7. Savings Goals

- Allow students to create savings goals.

- Display progress towards each goal.

8. Settings

- Allow users to change their name and currency.

- Provide a reset option.

FUNCTIONAL REQUIREMENTS:

- All buttons and navigation links must work.

- Expenses must be saved and remain available after refreshing the page using browser local storage.

- Charts must update automatically when transactions change.

- Budget calculations must be accurate.

- Use Indian Rupees (₹) as the default currency.

- Include realistic sample transactions for the first demonstration.

- Do not require payment or external financial account connections.

Make the final product look like a real student finance-management application that is suitable for a first-year engineering LTPS project.
